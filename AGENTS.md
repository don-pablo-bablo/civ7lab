# Agent guide

Read [CONTRIBUTING.md](CONTRIBUTING.md) first. It has the layout of the code,
the code rules, what is confirmed in game, and the writing style. Everything
below is extra, for agents only.

## Working with the maintainer

- **Confirmed or not**: do not present anything as working unless
  CONTRIBUTING.md lists it as confirmed or you have just measured it.
- **Restarts**: every time something is to be checked in game, say whether it
  needs a game restart. Mod files are read at game start, and a check against a
  stale build looks exactly like a check against a fresh one. `civ7lab logs
  stamps` shows which build ran.
- **Logs**: the game empties every log at launch. Copy first, read second.
  `civ7lab logs snapshot` and `civ7lab run` both do it.
- **Cheapest route**: offline, then live, then logs, then a full run. A
  question the SQL harness can answer should never cost a launch.
- **Launches**: starting the game is the maintainer's call. Ask first.
- **Screen checks**: make one visual change at a time and wait for the
  maintainer to look before reverting it.

## Commits

Do not add AI co-author or "generated by" lines to commits or pull requests.
